## Основные возможности

*   **Архитектура БД:** Спроектирована оптимальная схема для сущностей: Вопросы, Ответы, Теги, Профили и система лайков.
*   **Система лайков:** Реализована защита от "накрутки" на уровне базы данных (`unique_together`).
*   **Тонкие контроллеры:** Вся бизнес-логика и сложные выборки вынесены в `ModelManager` и методы моделей.
*   **Оптимизация (Anti N+1):** Использование `select_related` и `prefetch_related` для минимизации количества запросов.
*   **Пагинация:** Кастомная функция пагинации для всех списковых страниц.
*   **Админка:** Полностью локализованная (RU) панель управления с оптимизированными Inlines.
## Быстрый старт

### 1. Переменные окружения
Создайте файл `.env.docker` в корне проекта (используйте `.env.example` как шаблон):
```bash
cp .env.example .env.docker
```
### 2. Запуск в Docker
Все зависимости, включая базу данных, разворачиваются одной командой:

```bash
docker-compose up -d --build
```

### 3. Подготовка базы
Выполните миграции и создайте администратора:

```bash
docker-compose exec web python manage.py migrate
docker-compose exec web python manage.py createsuperuser
```
Генерация тестовых данных

```bash
docker-compose exec web python manage.py fill_db 10000
```
Объем данных (при коэффициенте 10 000):

10 000 пользователей и тегов.

100 000 вопросов.

1 000 000 ответов.

2 000 000 оценок.
