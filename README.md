# README
## HW5
* Добавлена возможность ставить лайки/дизлайки на вопросы и ответы
* Автор вопроса может помечать ответы правильными.
* Аватарки пользователей теперь сохраняются под уникальным именем.
## Быстрый старт

### 1. Переменные окружения
Создайте файл `.env.docker` в корне проекта (используйте `.env.example` как шаблон):
```bash
cp .env.example .env.docker
```
### 2. Запуск в Docker
Все зависимости, включая базу данных, разворачиваются одной командой:

```bash
docker-compose up -d --build
```

### 3. Подготовка базы
Выполните миграции и создайте администратора:

```bash
docker-compose exec web python manage.py migrate
docker-compose exec web python manage.py createsuperuser
```
Генерация тестовых данных

```bash
docker-compose exec web python manage.py fill_db 10000
```
Объем данных (при коэффициенте 10 000):

10 000 пользователей и тегов.

100 000 вопросов.

1 000 000 ответов.

2 000 000 оценок.
